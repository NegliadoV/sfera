# Дизайн-система «Ноосфера»

## 1. Текущий дизайн (по index.html)

- **Стиль:** Discord/Slack — тёмная тема, скруглённые карточки, акцент blurple (#5865f2).
- **Структура:** Верхняя панель (логотип, поиск, пользователь) → основной лейаут (сайдбар 280px + контент).
- **Цвета:** Фон #1e1f22 / #2b2d30 / #232428, текст #e1e3e6, вторичный #9b9da2, акцент #5865f2, зелёный #23a55a.
- **Компоненты:** nav-item с иконками, info-card, mind-map-item, форма «Добавить материал» с toggle Ссылка/Статья, action-btn.

---

## 2. Новый дизайн: тренды и UX

### 2.1 Ориентация на тренды (2025–2026)

- **Liquid Glass / стекло:** полупрозрачные панели, лёгкое размытие (backdrop-filter), мягкие тени.
- **Чистая иерархия:** чёткие уровни заголовков, больше воздуха, предсказуемые отступы (8px grid).
- **Физичность:** кнопки и карточки с лёгкой «глубиной» (тень, граница), hover/focus с плавными переходами.
- **Адаптивность:** мобильный первый подход; сайдбар сворачивается в бургер/нижнюю навигацию на узких экранах.
- **Доступность:** контраст WCAG AA, фокус-кольца, размеры касаний ≥ 44px.

### 2.2 Ссылка на интерфейс iPhone (iOS 26 / 2026)

- Крупные заголовки, много «воздуха».
- Секции с заголовками и списками в стиле Settings: группа заголовок → ряд элементов.
- Стеклянные панели (frosted) для хедера и панелей действий.
- Акцентный цвет один — используется для кнопок, ссылок, выбранного состояния; пользователь может менять (как «акцент» в iOS).
- Светлая и тёмная тема с переключением.

### 2.3 UX-принципы

- **Понятная навигация:** хлебные крошки, явный «текущий раздел», минимум уровней вложенности.
- **Быстрые действия:** основные действия (добавить материал, создать карту/комнату) на видном месте, без лишних кликов.
- **Обратная связь:** загрузка (скелетоны/спиннеры), успех/ошибка тостами или inline.
- **Единообразие:** одни и те же паттерны для списков (карточки, иконка + заголовок + мета), форм (label + input + подсказка).

## 3. Темы и кастомизация

### 3.1 Режимы

- **Тёмная тема (dark):** фон тёмно-серый, текст светлый — по умолчанию.
- **Светлая тема (light):** фон светло-серый/белый, текст тёмный.

### 3.2 Кастомный акцент

- Пользователь выбирает **акцентный цвет** (как в iOS: синий, фиолетовый, зелёный и т.д.).
- Используется для: кнопок «Создать/Добавить», активного пункта навигации, ссылок, фокуса полей ввода, бейджей.
- Сохраняется в `localStorage` и подставляется в CSS-переменную `--accent-primary` (и при необходимости `--accent-primary-hover`).

### 3.3 Техническая реализация

- В корне документа задаётся `data-theme="light" | "dark"` и при необходимости `data-accent` или стиль с `--accent-primary`.
- Все цвета интерфейса выражены через CSS-переменные; переключение темы = смена набора переменных.
- Скрипт в `<head>` до первого кадра считывает сохранённую тему из `localStorage` и выставляет атрибуты, чтобы не было мигания.

## 4. Структура интерфейса

- **Верхняя панель:** логотип, поиск (по контенту/вселенным), аватар + меню (профиль, настройки, выход). В настройках — раздел «Внешний вид» (тема + цвет).
- **Сайдбар:** секции «Вселенные», «Разделы» (Контент, Комнаты, Ментальные карты, Агрегатор), «Общее» (Профиль, Настройки, Дайджест). Активный пункт подсвечен акцентом.
- **Контент:** хлебные крошки → заголовок страницы/вселенной → описание (если есть) → блоки (форма добавления, фильтры, список карточек/карт/комнат).
- **Карточки:** единый стиль — фон, скругление, граница, при hover — лёгкое выделение; внутри — иконка/тип, заголовок, мета (автор, дата, теги).

---

## 5. Файлы и компоненты

- `app/globals.css` — переменные для dark/light и акцента, базовые классы.
- `components/ThemeProvider.tsx` — клиентский провайдер: чтение/запись темы и акцента, применение к документу.
- `app/settings/page.tsx` (или подстраница) — блок «Внешний вид»: переключатель светлая/тёмная тема, выбор акцентного цвета (палитра).
- Скрипт `theme-init.js` (inline в layout) — установка `data-theme` и акцента до рендера, чтобы избежать мигания.
