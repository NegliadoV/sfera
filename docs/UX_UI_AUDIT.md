# Проверка UX/UI (аудит и внесённые правки)

**Дата:** 2025-02-11

## Внесённые правки (сделано автоматически)

### 1. Дизайн-система и темы
- **Глобальные CSS-переменные:** добавлены `--bg` (алиас для фона полей ввода), `--border` (алиас для `--border-color`), `--header-bg` для шапки.
- **Шапка (Header):** фон задаётся через `var(--header-bg)` — в светлой теме шапка светлая, в тёмной тёмная (раньше был жёстко задан тёмный цвет).
- **Страница входа:** разделитель блока Dev использует `var(--border-color)` вместо несуществующей `var(--border)`.

### 2. Доступность
- **Фокус:** в `globals.css` добавлены стили `:focus-visible` для кнопок, ссылок, полей ввода и текстареа (контур 2px в цвет акцента). Улучшена навигация с клавиатуры.
- **Переключатель темы:** у кнопки уточнён `aria-label`: «Переключить тему (светлая/тёмная)», у иконки добавлен `aria-hidden`.

### 3. Обсуждения (DiscussionBlock)
- **Ошибки:** при неуспешной отправке комментария показывается сообщение об ошибке (сеть или ответ API).
- **Тип комментария:** радио-кнопки оформлены как понятные «пилюли» с рамкой и подсветкой выбранного типа, добавлены `role="radiogroup"` и `aria-label="Тип комментария"`.

### 4. Навигация
- В футер добавлена ссылка «Дайджест» для быстрого перехода на `/digest`.

## Рекомендации (что можно сделать при необходимости)

### Вам стоит сделать вручную (по желанию)

1. **Визуальная проверка**
   - Пройти по основным сценариям: главная → вселенные → вселенная → контент → обсуждение, вход/регистрация, настройки, комнаты, ментальные карты, агрегатор.
   - Убедиться, что в **светлой теме** все экраны читаемы (шапка, карточки, кнопки, поля ввода).
   - Проверить переключение темы (иконка в шапке) и сохранение выбора при перезагрузке (уже есть через `localStorage`).

2. **Иконка переключателя темы**
   - Сейчас в кнопке темы всегда отображается 🌙. По желанию можно показывать солнце в тёмной теме и луну в светлой (нужно проверять класс `dark-theme` на `document.documentElement` и менять символ/иконку).

3. **Страница 404**
   - Добавить кастомную страницу `app/not-found.tsx` в стиле Ноосферы (ссылка «На главную» / «К вселенным») вместо дефолтной Next.js.

4. **Загрузка и скелетоны**
   - На тяжёлых страницах (лента контента, список комнат) при желании добавить скелетоны или индикатор загрузки (например, через `loading.tsx` в App Router).

5. **Мобильное меню**
   - На узких экранах шапка с несколькими ссылками может съезжать. При необходимости добавить бургер-меню и выезжающую панель навигации.

6. **Дайджест для неавторизованных**
   - Ссылка «Дайджест» в футере ведёт на `/digest`; при отсутствии сессии произойдёт редирект на вход — это ожидаемо. При желании можно скрывать ссылку «Дайджест» для гостей или показывать подсказку «Войдите, чтобы видеть дайджест».

## Соответствие плану (PLAN.md)

- Используются токены из макета: цвета, радиусы, отступы, типографика (Inter, JetBrains Mono).
- Шапка: sticky, логотип, переключатель темы, CTA «Начать познание».
- Карточки: левая полоска-градиент, теги (pill), семантические реакции.
- Режим фокуса: зелёный pill с индикацией в шапке и на странице вселенной.
- Реакции: кнопки с иконкой/текстом, фон `--bg-accent`, без «лайков».

Все внесённые правки сохраняют единый стиль с описанным в плане и с дизайн-токенами.
