# Как освободить порт 6379

Если при установке Memurai Developer появляется ошибка "Service port is already in use. Please free port 6379", значит старый Redis 3.x все еще использует этот порт.

## Вариант 1: Через PowerShell от администратора (рекомендуется)

1. **Запустите PowerShell от имени администратора:**
   - Нажмите `Win + X`
   - Выберите "Windows PowerShell (Администратор)" или "Терминал (Администратор)"

2. **Перейдите в папку проекта:**
   ```powershell
   cd C:\Users\stanis\Desktop\Horizon_project
   ```

3. **Запустите скрипт:**
   ```powershell
   .\scripts\stop-redis-port.ps1
   ```

## Вариант 2: Через Диспетчер задач

1. Откройте **Диспетчер задач** (`Ctrl + Shift + Esc`)
2. Перейдите на вкладку **"Подробности"**
3. Найдите процесс **redis-server.exe** (PID: 22832 или другой)
4. Щелкните правой кнопкой → **"Завершить задачу"**

## Вариант 3: Через командную строку от администратора

1. Запустите **Командную строку от имени администратора**
2. Выполните:
   ```cmd
   taskkill /F /PID 22832
   ```
   (Замените 22832 на актуальный PID из `netstat -ano | findstr :6379`)

## Вариант 4: Через службы Windows

1. Нажмите `Win + R`, введите `services.msc` и нажмите Enter
2. Найдите службу **Redis** или **Memurai**
3. Щелкните правой кнопкой → **"Остановить"**

## Проверка

После остановки проверьте, что порт свободен:

```powershell
netstat -ano | findstr :6379
```

Если команда ничего не выводит, порт свободен.

Теперь можно установить Memurai Developer.
