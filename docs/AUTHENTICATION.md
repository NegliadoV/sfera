# Аутентификация в Horizon

Для использования большинства API эндпоинтов требуется авторизация. Ошибка "Unauthorized" означает, что вы не вошли в систему.

## Как войти

### Вариант 1: Регистрация и вход по email

1. **Регистрация:** откройте http://localhost:3000/auth/register, укажите email, пароль (не менее 8 символов) и при желании имя. После успешной регистрации вы попадёте на страницу входа.
2. **Вход:** на http://localhost:3000/auth/signin введите email и пароль и нажмите «Войти».

Пароли хранятся в виде хеша (scrypt) в поле `user.password_hash`. Seed-пользователь и пользователи, созданные через Google OAuth, не используют пароль.

### Вариант 2: Seed-пользователь (для разработки)

1. Откройте http://localhost:3000/auth/signin
2. Нажмите кнопку **"Войти как seed-пользователь"**
3. Вы будете автоматически авторизованы как seed-пользователь

**Seed-пользователь:**
- Email: `seed@horizon.local`
- ID: `00000000-0000-0000-0000-000000000001`
- Является владельцем всех вселенных, созданных через сидер

### Вариант 3: Google OAuth

1. Откройте http://localhost:3000/auth/signin
2. Нажмите **"Войти через Google"**
3. Авторизуйтесь через Google аккаунт

**Примечание:** Для работы Google OAuth добавьте в `.env`:
- `AUTH_GOOGLE_ID` — Client ID из Google Cloud Console
- `AUTH_GOOGLE_SECRET` — Client Secret

Если эти переменные не заданы, кнопка «Войти через Google» на странице входа не показывается (используйте вход как seed-пользователь). Ошибка **401 invalid_client** при входе через Google означает, что ID/Secret не заданы или неверны.

## Какие API требуют авторизации

- `POST /api/universes` — создание вселенной
- `POST /api/content` — создание контента
- `POST /api/universes/[slug]/sources` — добавление источника
- `POST /api/universes/[slug]/aggregate` — запуск агрегации
- `POST /api/content/[id]/links` — создание связи
- `POST /api/content/[id]/comments` — добавление комментария
- `POST /api/reactions` — добавление реакции

## Какие API не требуют авторизации

- `GET /api/universes` — список вселенных
- `GET /api/universes/[slug]` — информация о вселенной
- `GET /api/content` — список контента (с фильтрами)
- `GET /api/content/[id]` — информация о контенте
- `GET /api/content/[id]/comments` — список комментариев
- `GET /api/content/[id]/links` — список связей

## Проверка авторизации

После входа вы сможете:
- Создавать вселенные
- Добавлять контент
- Настраивать агрегатор
- Комментировать и реагировать

## Решение проблем

**Ошибка "Unauthorized" при использовании API:**
- Убедитесь, что вы вошли в систему (проверьте http://localhost:3000/auth/signin)
- Проверьте, что сессия активна (попробуйте обновить страницу)

**Ошибка "Forbidden" (403):**
- Вы не являетесь владельцем вселенной
- Вы не являетесь модератором вселенной
- Для некоторых действий нужны права владельца/модератора
