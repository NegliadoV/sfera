- ✅ Создание комнаты «по материалу» со страницы контента (ссылка + предзаполнение формы)
- ✅ **Real-time (Socket.io)**: обновление списка участников и состояния комнаты без перезагрузки. Запуск: `npm run ws` (отдельный процесс на порту 3002). Переменные: `WS_PORT`, `WS_SERVER_URL` (для API), `NEXT_PUBLIC_WS_URL` (для клиента).

### API комнат
- `GET /api/universes/[slug]/rooms` — список комнат
- `POST /api/universes/[slug]/rooms` — создание комнаты
- `GET /api/universes/[slug]/rooms/[roomId]` — комната с раундами и участниками
- `PATCH /api/universes/[slug]/rooms/[roomId]` — действия создателя (start, next_round, finish)
- `POST /api/universes/[slug]/rooms/[roomId]/join` — войти
- `POST /api/universes/[slug]/rooms/[roomId]/leave` — выйти

## 📊 API Endpoints

### Вселенные
- `GET /api/universes` — список вселенных
- `POST /api/universes` — создание вселенной
- `GET /api/universes/[slug]` — информация о вселенной
- `POST /api/universes/[slug]/aggregate` — запуск агрегации

### Источники
- `GET /api/universes/[slug]/sources` — список источников
- `POST /api/universes/[slug]/sources` — добавление источника
- `PATCH /api/universes/[slug]/sources/[sourceId]` — обновление источника
- `DELETE /api/universes/[slug]/sources/[sourceId]` — удаление источника

### Контент
- `GET /api/content?universeId=...` — список контента (с фильтрами)
- `POST /api/content` — создание контента
- `GET /api/content/[contentId]` — информация о контенте
- `GET /api/content/[contentId]/comments` — комментарии
- `POST /api/content/[contentId]/comments` — создание комментария
- `PATCH /api/content/[contentId]/comments/[commentId]` — редактирование комментария
- `DELETE /api/content/[contentId]/comments/[commentId]` — удаление комментария
- `GET /api/content/[contentId]/links` — связи контента
- `POST /api/content/[contentId]/links` — создание связи

### Реакции
- `GET /api/reactions?targetType=...&targetId=...` — получение реакций
- `POST /api/reactions` — создание/изменение реакции

### Комнаты (Фаза 3)
- См. раздел «Фаза 3» выше.

## 🔧 Технические детали

### База данных
- PostgreSQL с Drizzle ORM
- Схема включает все таблицы для Фаз 0-2

### Очереди
- BullMQ для фоновых задач
- Redis для хранения очередей
- Worker для обработки задач агрегации

### Провайдеры агрегации
- RSS/Atom парсер (`lib/aggregator/providers/rss.ts`)
- YouTube Data API v3 (`lib/aggregator/providers/youtube.ts`)

### Авторизация
- NextAuth.js v5 с Drizzle adapter
- Сессии в базе данных
- Cookies для передачи сессий

## 🚀 Как использовать

1. **Запустить сервисы:**
   ```bash
   npm run dev          # Dev сервер
   npm run worker       # Worker для очередей
   npm run ws           # WebSocket-сервер для real-time комнат (порт 3002)
   # Redis должен быть запущен (для worker)
   ```

2. **Войти:**
   - Открыть http://localhost:3000/auth/signin
   - Нажать "Войти как seed-пользователь"

3. **Создать вселенную:**
   - Перейти на http://localhost:3000/universes
   - Создать новую вселенную

4. **Настроить агрегатор:**
   - Открыть вселенную
   - Перейти в "Настройки агрегатора"
   - Добавить источники (RSS, YouTube)
   - Запустить агрегацию

5. **Добавить контент вручную:**
   - На странице вселенной использовать форму "Добавить материал"

6. **Обсуждать:**
   - Открыть контент
   - Добавить комментарий с типом
   - Поставить реакцию

## 📝 Примечания

- Для YouTube агрегации нужен API ключ в `.env`: `YOUTUBE_API_KEY=...`
- Seed-пользователь создаётся при `npm run db:seed`
- Все запросы теперь включают `credentials: 'include'` для передачи cookies
