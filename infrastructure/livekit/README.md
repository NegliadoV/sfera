# 🚀 Деплой LiveKit на Ubuntu (VPS) с Nginx

Эта инструкция описывает перенос папки `livekit` на ваш сервер и проброс публичного WebRTC потока без конфликтов с вашими существующими сайтами.

## 1. Открытие портов в фаерволе (UFW)
LiveKit требует широкий спектр UDP портов, иначе звук просто не пойдет.
Зайдите по SSH на сервер и выполните:
```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 50000:60000/udp
```
*(Если у вас другой фаервол, или внешний шлюз облачного провайдера, убедитесь что эти порты открыты там тоже)*.

## 2. Скопируйте файлы на сервер
Скопируйте папку `infrastructure/livekit` себе на сервер, например, в путь `/opt/livekit/`.

## 3. Запуск Docker-контейнера
На сервере перейдите в папку `/opt/livekit/` и запустите контейнер:
```bash
cd /opt/livekit/
sudo docker-compose up -d
```
Служба LiveKit теперь слушает порт `7880` внутри ВАШЕГО сервера.

## 4. Сертификаты и Nginx
Добавьте А-запись с поддоменом `rtc.ваш-домен.com` у вашего регистратора (указывающую на IP вашего VPS). Ваш фронтенд будет подключаться к этому поддомену, чтобы найти WebRTC.

Затем скопируйте содержимое файла `nginx.conf` и вставьте его в настройки вашего nginx (в `/etc/nginx/sites-available/default` или рядом с вашим конфигом проекта). Замените строки `rtc.ВАШ_ДОМЕН.com` на ваш реальный поддомен.

Получите SSL-сертификаты с помощью `certbot`.
```bash
sudo certbot --nginx -d rtc.ВАШ_ДОМЕН.com
```

Отлично! Конфиг Nginx автоматически сделает **Reverse Proxy Websockets** с вашего HTTPS `rtc.домен.com` в порт Docker'а `7880`.

## 5. Подключение в Horizon
Теперь ваш собственный LiveKit крутится на вашем собственном VPS.
Откройте локальный файл `.env` в проекте Horizon и поменяйте:
```env
# Используйте схему wss://, а не https://
NEXT_PUBLIC_LIVEKIT_URL="wss://rtc.ваш-домен.com" 
LIVEKIT_API_KEY="AJtBv8a8FjL9xX"
LIVEKIT_API_SECRET="Nqk9s2M9aWk3pYm1B9gR0jL3hF2vB4"
```
Свои ключи вы можете поменять в файле `livekit.yaml` (обязательно перезапустите Docker `docker-compose restart`, если меняете там ключи).
