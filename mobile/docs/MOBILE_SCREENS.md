# Экраны мобильного приложения

## Реализовано полностью

| Экран | Описание |
|-------|----------|
| Вход | Логин по email/паролю и seed-вход |
| Регистрация | Регистрация нового пользователя |
| Таб «Вселенные» | Список вселенных, переход в детали вселенной |
| Вселенная (детали) | Название, описание, ссылки: Контент, Комнаты, Ментальные карты |
| Контент вселенной | Список материалов по вселенной |
| Комнаты вселенной | Список комнат просмотра |
| Ментальные карты | Список ментальных карт |
| Таб «Я» | Профиль + «Мой контент» |
| Таб «Сборка» | Контент за 24 часа |
| Таб «Настройки» | Выход, email |

## Добавленные экраны (следующие страницы)

| Экран | Файл | Описание |
|-------|------|----------|
| **Чат (DM)** | `(tabs)/messages/[userId].tsx` | Переписка с пользователем: загрузка сообщений, отправка. Работает при поддержке JWT в API (`getSessionForRequest` в `/api/me/conversations/[userId]` и `.../messages`). |
| **Групповой чат** | `(tabs)/messages/group/[groupId].tsx` | Сообщения группы, отправка. Аналогично требует JWT в `/api/me/group-chats/[groupId]/messages`. |
| **Материал** | `(tabs)/universes/[slug]/content/[contentId].tsx` | Один материал: заголовок, автор, тело, ссылка. API `GET /api/content/[contentId]` без авторизации — работает из мобилки. |
| **Комната** | `(tabs)/universes/[slug]/rooms/[roomId].tsx` | Заголовок комнаты; полноценный синхронный просмотр — в веб-версии. |
| **Ментальная карта** | `(tabs)/universes/[slug]/mind-maps/[mapId].tsx` | Название карты; просмотр/редактирование — в веб-версии. |

Навигация: из списка сообщений — тап по чату (DM или группа), из контента — по материалу, из комнат — по комнате, из ментальных карт — по карте.

## Что доработать на бэкенде для мобилки

Чтобы чаты (DM и группа) работали с мобильным JWT, в маршрутах нужно получать сессию через `getSessionForRequest(req)` вместо `auth()` (cookies):

- `app/api/me/conversations/[userId]/route.ts` (GET)
- `app/api/me/conversations/[userId]/messages/route.ts` (POST)
- `app/api/me/group-chats/[groupId]/messages/route.ts` (GET/POST)
